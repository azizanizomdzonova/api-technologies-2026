### Замер производительности и проверка SLA

1. **Инструмент и стенд**: нагрузочный скрипт services/gateway/app/bench_p95.py
2. **Методика**: перед замером выполняется 5 прогревочных запросов. Затем отправляется 1 000 POST-запросов на http://localhost:8000/v1/transactions/evaluate с параллельностью concurrency = 2 и замером времени ответа через time.perf_counter()
3. **За счёт чего соблюдается SLA**: Чтение всех 4 признаков из Redis за 1 сетевой вызов (pipeline), постоянные каналы grpc.aio с таймаутами, вынос фонового обновления агрегатов в asyncio.create_task.

```bash 
python services/gateway/app/bench_p95.py
```

| Метрика | Значение | Требование ТЗ | Статус |
|---|---|---|---|
| Всего запросов | `1000` (`concurrency = 2`) | `1000` | OK |
| Успешных (`200 OK`) / Ошибок | `1000` / `0` | `0` ошибок | OK |
| Пропускная способность | `32.9 RPS` | — | — |
| Среднее время (`avg`) | `60.65 мс` | — | — |
